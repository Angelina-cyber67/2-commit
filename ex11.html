HTML

O que é?

  • HTML é a sigla para Linguagem de Marcação de Hiper Texto (Hiper Text Markup Language), e é o esqueleto de uma página web
  • HTML é uma linguagem de marcação utilizada na construção de páginas web.
  • HTML utiliza "tags" para estruturar o conteúdo da página.
  • As tags HTML são interpretadas pelos navegadores para exibir texto, imagens, links e outros elementos.

CSS

O que é?

  • CSS é a sigla para Folha de Estilo em Cascata (Cascading Style Sheets)
  • CSS é uma linguagem de estilo utilizada para descrever a apresentação de um documento HTML.
  • CSS permite separar o conteúdo (HTML) da apresentação (estilo visual).
  • Com CSS, é possível controlar cores, fontes, layouts e outros aspectos visuais de uma página web.

JavaScript

O que é?

  • JavaScript é uma linguagem de programação que permite adicionar interatividade às páginas web.
  • JavaScript é executado no lado do cliente (navegador) e pode manipular o conteúdo HTML e CSS dinamicamente.
  • Com JavaScript, é possível criar efeitos visuais, validar formulários, carregar conteúdo de forma assíncrona e muito mais.
